# ClipForge — ข้อมูลสำหรับผู้รีวิววิดีโอจากภายนอก

> เอกสารนี้เขียนให้ **ChatGPT หรือ AI/คนอื่นที่ได้ดูแค่ไฟล์ `job_XX_final.mp4`** แล้วต้องให้
> ความเห็น โดยไม่เห็นโค้ด ไม่เห็น log และไม่รู้ว่าระบบทำอะไรไปแล้วบ้าง
>
> **โปรดอ่านทั้งไฟล์ก่อนให้คำแนะนำ** เพราะข้อเสนอที่ผ่านมาหลายข้อเป็นสิ่งที่ระบบทำอยู่แล้ว
> หรือทำไม่ได้ด้วยเหตุผลเชิงโครงสร้าง
>
> อัปเดตล่าสุด: 30 ก.ค. 2026

## 1. ระบบนี้คืออะไร

บอทสร้างคลิปรีวิวสินค้าแนวตั้งความยาว 16 วินาที สำหรับลงโซเชียล โดยอัตโนมัติทั้งหมด
ตั้งแต่ดึงข้อมูลสินค้าจาก Shopee จนได้ไฟล์ mp4 พร้อมเสียงพากย์ไทย

**ข้อจำกัดที่สำคัญที่สุดต่อการรีวิว:** ระบบ **ไม่มีสิทธิ์เข้าถึงโมเดลวิดีโอโดยตรง**
มันควบคุม **Google Flow ผ่านหน้าเว็บ** ด้วย Chrome Extension เหมือนคนนั่งคลิกเอง
สิ่งที่ควบคุมได้จริงมีแค่:

- รูปที่อัปโหลดเข้าไป
- ข้อความ prompt ที่พิมพ์
- ตัวเลือกใน UI (โมเดล, อัตราส่วน, ความยาว)

**ควบคุมไม่ได้เลย:** seed, guidance scale, ControlNet, IP-Adapter, LoRA, negative prompt,
การเข้าถึง latent, การ inpaint หรือ API ใดๆ ของโมเดล

ดังนั้นข้อเสนอที่ต้องใช้ความสามารถระดับ API ของโมเดลจะทำไม่ได้ทั้งหมด

## 2. Pipeline จริง (ตามลำดับ)

```
1. Shopee Harvester (Chrome Extension) เก็บ spec + รูปทางการ + รีวิว
2. Gemini อ่านรูปทางการ 9 รูป → เลือก 1 รูป + วางสตอรี่บอร์ด 2 ช็อต + เขียน prompt
3. Flow (Nano Banana) เจนรูป "มือถือสินค้า" จากรูปที่เลือก        ← จ่ายเครดิต
4. ด่านตรวจ: Gemini เทียบรูปที่เจนกับรูปต้นฉบับ ไม่ตรง = หยุดงาน   ← กันเผาเครดิตวิดีโอ
5. Flow เจนคลิป 8 วิ ด้วยโหมด "ส่วนผสม" = รูปข้อ 3 + รูปทางการอีก 3 ใบ ← จ่ายเครดิต
6. ด่านตรวจเฟรมแรกของคลิป เทียบกับรูปอ้างอิง (เตือน ไม่ทิ้งคลิปที่จ่ายแล้ว)
7. ffmpeg ดึงเฟรมสุดท้ายของคลิป 1 → ใช้เป็นเฟรมเริ่มของคลิป 2
8. Flow เจนคลิป 2 ต่อจากเฟรมนั้น (โหมดเฟรม)                       ← จ่ายเครดิต
9. Gemini ดูคลิปจริงที่ได้ + รู้ว่าช็อตนั้นสั่งให้ทำท่าอะไร แล้วเขียนบทพากย์ให้ตรงกับภาพ
10. Gemini TTS พากย์ไทย → ffmpeg จัดจังหวะให้ตรงช่อง 8 วิ ต่อคลิป
11. ffmpeg ต่อคลิป + ผสมเสียง + upscale → job_XX_final.mp4
```

## 3. สิ่งที่ทำอยู่แล้ว — ไม่ต้องเสนอซ้ำ

| สิ่งที่มักถูกเสนอ | สถานะจริง |
|---|---|
| ใช้เฟรมสุดท้ายของคลิปก่อนหน้าเป็น reference ของคลิปถัดไป | ✅ **ทำอยู่แล้ว** (ไฟล์ `continuity_N.jpg` อยู่ในโฟลเดอร์งานทุกงาน) |
| ล็อกให้คลิปถัดไปใช้มือ/แสง/กล้อง/พื้นหลังเดิม | ✅ อยู่ใน continuation prompt ทุกคลิป |
| ห้าม AI แต่งตารางโภชนาการ/ฉลากขึ้นเอง | ✅ อยู่ใน image prompt |
| ตรวจว่าสินค้าตรงต้นฉบับก่อนจ่ายเครดิตวิดีโอ | ✅ ด่าน fidelity (ขั้นที่ 4) และเช็คซ้ำที่เฟรมแรกของคลิป (ขั้นที่ 6) |
| เขียนบทพากย์จากคลิปจริง ไม่ใช่เดาล่วงหน้า | ✅ ขั้นที่ 9 (มีบทสำรองถ้าล้ม) |
| ให้คำพูดตรงกับสิ่งที่เห็นในช็อต | ✅ คนเขียนบทได้รับ "ท่าที่ช็อตนั้นถูกสั่งให้ทำ" ไปด้วย (แก้ 30 ก.ค.) |
| Hook ต้นคลิป + CTA ปิดท้าย | ✅ บังคับในกฎเขียนบท |
| ห้ามบทพากย์อ้างสรรพคุณที่ไม่มีข้อมูลรองรับ | ✅ ตัดคำอ้างออกอัตโนมัติ |
| ตัดช่วงเงียบ / จัดจังหวะเสียงให้ตรงคลิป | ✅ สองรอบ: ตัดเงียบผิดปกติ แล้ว fit tempo |
| เพลงพื้นหลัง + normalize -14 LUFS | ✅ โค้ดพร้อม (ดูข้อ 6) |
| ซับไตเติล | ✅ สร้าง `.srt` เสมอ แต่ไม่เบิร์นลงภาพโดยค่าเริ่มต้น |
| Export 1080×1920 (ไม่แตะเฟรมเรต) | ✅ เปิดอยู่ (`OUTPUT_UPSCALE=true`) |

## 4. ค่าที่ใช้อยู่จริงตอนนี้

| ค่า | ค่าปัจจุบัน |
|---|---|
| คลิปต้นทางจาก Flow | 720×1280 / 24fps / 8 วินาที × 2 คลิป |
| ไฟล์ปลายทาง | 1080×1920 / **24fps คงเดิม** / ~2.6 Mbps (crf 20) |
| การหมุนสินค้าที่อนุญาต | **8 องศา** ซ้าย-ขวา (ลดจาก 20° เมื่อ 27 ก.ค.) |
| ช่วงเงียบท้ายแต่ละคลิป | 0.35 วินาที (ลดจาก 0.7) |
| ความยาวบทต่อคลิป | 86–100 ตัวอักษร |
| เสียงพากย์ | Gemini TTS เสียง Aoede |
| ระดับเสียง | พากย์ + บรรยากาศจาก Veo (0.18) + เพลง (0.08) → −14 LUFS |
| พักระหว่างคลิปในงานเดียวกัน | 1–3 นาที |
| พักก่อนเริ่มงานใหม่ | 3–5 นาที |
| End frame (start+end interpolation) | ❌ **ปิดอยู่** |
| แนบรูปทางการหลายมุมเป็น reference (วิธี A) | ✅ **เปิดอยู่** 2 รูป |
| เบิร์นซับลงภาพ | ❌ ปิดอยู่ |
| minterpolate 60fps | ❌ ปิดอยู่ (ช้า 5-6 นาที/คลิป) |

## 5. สิ่งที่ทำไม่ได้ พร้อมเหตุผล

### ❌ Product compositing / object tracking / วางภาพสินค้าจริงทับ

ต้องมี 3D tracker ติดตามสินค้าทุกเฟรม + mask แยกมือที่บังสินค้า + วาร์ปภาพสินค้าจริงตามมุมกล้อง
เป็นงานระดับ VFX ที่ต้องสร้างระบบใหม่ทั้งระบบ ไม่ใช่การปรับ pipeline เดิม
**ถ้าจำเป็นจริง ต้องคุยเป็นโปรเจกต์แยก**

### ❌ Audio crossfade ตรงรอยต่อคลิป

เสียงถูกตัดเป็นชิ้นละ 8 วินาทีให้ตรงกับคลิปเป๊ะ ถ้า crossfade 200ms ความยาวรวมจะหดลง
แล้วเสียงจะเลื่อนหลุดจากภาพทั้งคลิป → **แก้ที่ต้นเหตุ (หดช่วงเงียบ) แทน**
วิธีกลบรอยต่อที่ถูกต้องคือเพลงพื้นหลังต่อเนื่อง ไม่ใช่ crossfade เสียงพากย์

### ❌ ควบคุม seed / negative prompt / ControlNet / IP-Adapter

ดูข้อ 1 — ระบบคุยกับ Flow ผ่านหน้าเว็บเท่านั้น

### ❌ ลบลายน้ำ Gemini

เจ้าของตัดสินใจแล้วว่าไม่ทำ

### ❌ หาทางหลบระบบตรวจจับบอทของ Google

ถ้า Flow ขึ้น "กิจกรรมผิดปกติ" บอทจะหยุดและล็อกเครดิตทันที **ห้ามเสนอวิธีกดผ่าน**
(ปลอม fingerprint, จำลองการเคลื่อนเมาส์แบบคน, สุ่มจังหวะให้ดูเหมือนมนุษย์, เปลี่ยน proxy ฯลฯ)
สิ่งที่ยอมรับได้คือ **ลดปริมาณการใช้งานจริง** เท่านั้น

## 6. เรื่องที่เจ้าของทำเองได้ ยังไม่ได้ทำ

**โฟลเดอร์ `data/bgm` ว่างเปล่า** — ระบบรองรับเพลงพื้นหลังเต็มรูปแบบแล้ว (สุ่มเพลง + วนลูป +
mix ให้ได้ −14 LUFS) แต่ยังไม่มีไฟล์เพลง ใส่ `.mp3` ลงไปแล้วได้ผลทันที
**นี่คือวิธีกลบรอยต่อวินาทีที่ 8 ที่ได้ผลที่สุด**

## 7. ปัญหาที่ยังแก้ไม่ตก (ตรงนี้ต้องการความเห็นจริงๆ)

### 🔴 สินค้าและฉลากเพี้ยนระหว่างคลิป

Veo วาดสินค้าใหม่ทุกเฟรม ทำให้ตัวอักษรบนฉลากเปลี่ยนคำ กราฟิกย้ายที่ ฝา/คอขวดเปลี่ยนรูป
**ยังไม่หายขาด** สิ่งที่ทำไปแล้ว:

- ลดการหมุนเหลือ 8° (ยิ่งหมุนยิ่งต้องวาดด้านที่ไม่เคยเห็น)
- ล็อกตัวอักษรฉลาก / ระดับของเหลว / จุดที่นิ้วจับ ไว้ใน prompt ทุกคลิป
- ด่าน fidelity บล็อกรูปที่ไม่ตรงก่อนจ่ายเครดิตวิดีโอ

แต่ prompt ควบคุมได้แค่ระดับหนึ่ง **ยังไม่มีคำตอบที่ดีในกรอบที่ Flow เปิดให้**

### 🟠 ของนุ่มเปลี่ยนรูปทำให้ด่านตรวจสับสน

หมอน ผ้า เสื้อ เปลี่ยนทรงตามการจับวางเป็นธรรมดา ด่าน fidelity เคยตีตกรูปที่ถูกต้อง
แก้แล้วโดยให้ตัดสินที่โครงสร้าง (ตะเข็บ แถบขอบ สัดส่วน) ไม่ใช่ทรงชั่วขณะ — **ยังต้องดูผลระยะยาว**

### 🟠 ยังไม่มีข้อความบนจอ (ราคา/โปรโมชั่น/ประโยชน์)

ระบบสร้าง `.srt` อยู่แล้วแต่ไม่เบิร์นลงภาพ เพราะข้อความเดียวกับเสียงพากย์จะบังสินค้าและดูรก
ถ้าจะใส่ข้อความขาย ต้องเป็น **ข้อความคนละชุดกับบทพากย์** ซึ่งยังไม่ได้ออกแบบ

## 8. รีวิวแบบไหนที่มีประโยชน์ที่สุด

**มีประโยชน์มาก:**
- ชี้จุดเวลาที่มีปัญหา (เช่น "วินาทีที่ 9.5 ฝาขวดเปลี่ยนรูป")
- บอกว่าอาการไหนคนดูทั่วไปจะจับได้ อาการไหนต้องเพ่งถึงจะเห็น
- เทียบกับคลิปรีวิวสินค้าที่ขายได้จริง ว่าขาดอะไร
- ความเห็นเรื่องจังหวะ บท เสียง การเล่าเรื่อง

**ไม่มีประโยชน์:**
- ข้อเสนอที่ต้องใช้ API ของโมเดล (ดูข้อ 1)
- ข้อเสนอที่ระบบทำอยู่แล้ว (ดูข้อ 3)
- ข้อเสนอที่ต้องสร้างระบบใหม่ทั้งระบบ โดยไม่บอกว่าคุ้มกับต้นทุนยังไง

**ถ้าไม่แน่ใจว่าระบบทำอะไรอยู่แล้ว ให้ถามก่อน อย่าเดา**
