เลิกพึ่งคนขาย — สร้างระบบ Fleet ของเราเอง

แพลตฟอร์มควบคุมบอทหลายเครื่องแบบครบวงจร สำหรับ Shopee · TikTok · Facebook · Live — ใช้ระบบเดิม (Samurai) เป็นพิมพ์เขียว แต่สร้างใหม่ให้เป็นของเรา 100% และปลอดภัยกว่าเดิม

กรอบคิด: งาน reverse-engineering ที่เราทำ = สเปกของสิ่งที่ต้องมี. งาน security ที่เราเจอ = รายการสิ่งที่ ห้ามลอก (TLS ปลอม · updater ยัด APK · secret เปลือย). เป้าคือ “ทำงานเหมือนเดิม แต่เราคุมเซิร์ฟเวอร์เอง คีย์อยู่กับเรา และแก้ selector ได้โดยไม่ต้องออกแอปใหม่”. นี่เป็นงานระดับแพลตฟอร์ม (หลายเดือน หลายบริการ) — จึงต้องแบ่งเฟสให้เห็นผลเร็วและลดความเสี่ยงทีละชั้น.

Build it right

7 จุดที่เราจะทำต่างจากของเดิม (ห้ามลอกจุดพัง)

TLS ปลอม→ TLS จริง + certificate pinning ทุก call
updater เถื่อน→ ไม่มี auto-install; แจกผ่าน MDM/สโตร์ + verify signature
คีย์ AI ในเครื่อง→ Backend proxy call AI; device ไม่เคยเห็นคีย์
secret plaintext→ Android Keystore / EncryptedSharedPreferences
lock ไม่มี TTL→ lock หมดอายุอัตโนมัติ + idempotency key
selector hardcode→ selector map ดึงจากเซิร์ฟเวอร์ (Shopee เปลี่ยน UI แก้ที่เดียว)
cleartext HTTP→ HTTPS only, ไม่มี IP ฝัง, device register แบบเพิกถอนได้
Roadmap

ลำดับการสร้าง — เห็นผลเร็ว ลดเสี่ยงทีละชั้น

แต่ละเฟสได้ของที่ใช้งานได้จริง ไม่ต้องรอจบทั้งระบบ

0
Backbone

Backend core + device auth + 1 เครื่อง end-to-end

สร้าง Backend (auth/discover, dataset, command, status) + จับ Android app ที่มี (Clip Bot) มาต่อ พิสูจน์ลูป: สั่งจากเซิร์ฟเวอร์ → เครื่องทำคลิป → รายงานกลับ (ยังไม่ auto-post)

ได้: ลูปควบคุม 1 เครื่องทำงานจริง
1
Content + Source

Shopee scraper + เจนคลิปจากรีวิวจริง

Browser extension ดึงรีวิว Shopee → Backend สร้าง dataset → app เจนคลิป + AI caption (ผ่าน AI proxy) ครบ

ได้: คลิปรีวิวออกจริงจากสินค้าจริง
2
Fleet

Dashboard + คุมหลายเครื่องพร้อมกัน

เว็บคุม fleet, command queue, มอนิเตอร์เรียลไทม์, item lock กันชนข้ามเครื่อง (มี TTL)

ได้: คุม 5–50 เครื่องจากที่เดียว
3
Auto-post

โพสต์อัตโนมัติ Shopee → TikTok → Facebook

Accessibility automation ทีละแพลตฟอร์ม + ระบบ selector อัปเดตจากเซิร์ฟเวอร์ (จุดยาก/เปราะที่สุด ทำหลังฐานมั่นคง)

ได้: ปิดวงจรอัตโนมัติเต็ม
4
Expand

Live Assist + ปรับสเกล/ความทน

โมดูลช่วยไลฟ์ขาย + hardening, observability, กระจายโหลด

ได้: ครบเทียบเท่าชุด Samurai ทั้งหมด
